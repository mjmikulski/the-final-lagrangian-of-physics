# Appendix: the parity-odd exclusion is now addressed

*Companion file (METHOD rule 7); the report itself is immutable.*

Report 001 §6 excluded parity-odd invariants and noted, unverified, P239's
count of "four independent one-ε pseudoscalars". That sector is now closed
in [report 005](../005-epsilon-contractions/): the count of four holds only
on generic double two-forms — on realizable fields
$F(A)=[\partial_\mu M,\partial_\nu M]_\eta$ one of the four vanishes
identically (cyclic-trace identity), leaving **three** — and the 3×3
no-go of §5 extends verbatim to the entire ε sector.
